Tests tab — three ways

Kindle size, grayscale like your SimpleUI Home. Tap the tabs in each device: watch whether the tab bar stays, and what the Tests page shows. Sample tests and scores are illustrative.

A · Custom Screen + Leaf module recommended

A SimpleUI page like Home. Tab bar stays. Status, score and buttons per test.

+ native look, tabs always visible, no SimpleUI code changes. − a bit more setup (module + screen + tab).

B · Leaf full-screen page

Tab opens Leaf's own page. It covers the tab bar; you leave with ← Back.

+ simplest Leaf code, full freedom of layout. − tabs disappear on this page, unlike Home / Library / History.

C · Folder shortcut

Tab opens documents/IELTS in Library. Same grid as books.

+ almost no code. − no status, score or Continue; looks like any book folder.

The test-taking screen itself (passage page + Questions panel) is the same in all three.
