# Tests Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A **Tests** tab right after Home in SimpleUI that lists the IELTS tests in `documents/IELTS/` with status, score and Start / Continue / Review / Retry.

**Architecture:** Pure scanning/status logic (`english_tests.lua`) reads each test EPUB's embedded `META-INF/leaf-ielts.json` and the progress Leaf already saves, reusing `english_ielts` and `english_ielts_session`. A SimpleUI external module (`english_tests_module.lua`) renders it. Leaf registers the module, creates a SimpleUI Custom Screen holding it, and puts that screen's Quick Action after Home in the tab bar — once.

**Tech Stack:** KOReader Lua plugin (LuaJIT), SimpleUI external-module + Custom Screen APIs, KOReader `ffi/archiver`, `docsettings`, `lfs`.

**Spec:** `docs/superpowers/specs/2026-11-22-tests-tab-design.md` (mockup option A: `research/tests-tab-mockup.html`)

## Global Constraints
- No changes to SimpleUI's own code (`runtime/macos/test-data/plugins/simpleui.koplugin/**`); use only `modules/moduleregistry.lua` (`Registry.register`), `infra/sui_custom_screens.lua` (`M.create`, `M.qaId`), `infra/sui_store.lua` settings and `infra/sui_config.lua` tab config (`loadTabConfig`/`saveTabConfig`).
- Leaf works unchanged when SimpleUI is absent (every SimpleUI touch is pcall'd).
- Tests folder: `<home_dir>/IELTS` (KOReader `G_reader_settings:readSetting("home_dir")`, `/mnt/us/documents` on the Kindle).
- Home tab id is `"homescreen"`; Tests goes immediately after it. Max tabs is SimpleUI's `effectiveMaxTabs()`.
- Copy (exact): section labels `TESTS`, `CONTINUE`, `ALL TESTS`; summary labels `tests`, `finished`, `last band`; buttons `Start`, `Continue`, `Review`, `Retry`; empty state `No tests yet — put test files in documents/IELTS`; Retry confirm `Clear your answers for this test and start again?` with `Retry` / `Cancel`; full-bar hint `The tab bar is full. Add "Tests" from SimpleUI → Tab bar.`
- E Ink: grayscale, no animation, tap targets ≥ 44 px. Home must not get slower (scan results cached).
- All checks: `python3 runtime/macos/checks/run-learning-checks.py` stays green; new `.lua` checks registered there with the plugin dir as arg (like `english-ielts.lua`).

## Review Focus
1. **A broken or non-test EPUB in `IELTS/`** (no JSON, invalid JSON, not a zip) — skipped, others still listed, no error on Home. Test in Task 1.
2. **Test with progress saved but the file replaced by a newer version** (different size/mtime) — cache refreshes; stale answers beyond the new question count don't crash scoring. Test in Task 1.
3. **Tab already removed by the user / setup already done** — never re-added on later starts. Test in Task 3.
4. **SimpleUI page-arrows mode (max 4 tabs) with 4 tabs present** — nothing replaced, hint shown once. Test in Task 3.
5. **Returning to the Tests tab after finishing a test** — status shows the new score (no stale cache from before the test). Test in Task 1 (cache keyed on settings mtime too).

### Task 1: Test scanning and status

**Files:**
- Create: `runtime/macos/test-data/plugins/englishpreview.koplugin/english_tests.lua`
- Create: `runtime/macos/checks/english-tests.lua` (register in `run-learning-checks.py`)

**Interfaces:**
- Consumes: `english_ielts.parse(text)`, `.score(test, answers)`, `.band(right,total)`; `english_ielts_session.new(test, store)` with `:answered()`, `:remaining(now)`, `:finished()`, `:mode()`.
- Produces:
  - `Tests.scan(dir, io, now) -> items` where `io = {list=function(dir)->{path...}, stat=function(path)->{size,mtime}|nil, readJson=function(path)->string|nil, record=function(path)->table|nil, recordMtime=function(path)->number|nil}`. Each item: `{path, title, meta, total, minutes, state="new"|"progress"|"done", answered, remaining (seconds|nil), right, band, rough, active (recordMtime or 0)}`. `meta` = `"<n> Q · <minutes> min"` plus `" · <k> passages"` when more than one passage.
  - `Tests.summary(items) -> {count, finished, lastBand}` (`lastBand` = band of the finished test with the greatest `active`, or nil).
  - `Tests.continueItem(items) -> item|nil` (in-progress item with greatest `active`).
  - `Tests.ordered(items) -> items` (new, then progress, then done; title order inside each).
  - `Tests.defaultIO()` — real `io`: `lfs` listing of `.epub` files (not recursive), `ffi/archiver` `Reader:open` + `extractToMemory("META-INF/leaf-ielts.json")`, `require("docsettings"):open(path):readSetting("leaf_ielts")` for `record`, and the sidecar's modification time for `recordMtime` (DocSettings `getSidecarFile`/`lfs.attributes`).
  - Parsed tests are cached in a module table keyed by `path..size..mtime`; records are re-read every scan (they are small).

- [ ] **Step 1: Write the failing check** `english-tests.lua` with a fake `io` and two fake tests (build JSON strings inline; one 1-passage 6-question test, one 3-passage 40-question test):
  - not-started → `state=="new"`, `meta=="6 Q · 20 min"`; 3-passage `meta=="40 Q · 60 min · 3 passages"`.
  - record `{mode="practice",answers={[1]="TRUE",[3]={"A","C"}},elapsed=440}` → `state=="progress"`, `answered==3`, `remaining==760`.
  - study-mode record → `remaining==nil`.
  - record with `finished=true` → `state=="done"`, `right` = scored value, `band`/`rough` from `english_ielts.band`.
  - Review Focus 1: a path whose `readJson` returns nil, `"{"`, or errors → skipped, other items still returned.
  - Review Focus 2: record answers for question 99 on a 6-question test → no error, ignored.
  - Review Focus 5: same path, new `recordMtime`/record → second scan reflects the new state (no stale cache).
  - `summary`, `continueItem` (latest `active`), `ordered` order.
